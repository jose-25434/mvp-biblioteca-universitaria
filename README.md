# mvp-biblioteca-universitaria
MVP de sistema de gestión de préstamo y devolución de libros para biblioteca universitaria. Incluye análisis de requisitos (10 RF / 10 RNF), diagramas UML (casos de uso, clases, secuencia, estados), modelado BPMN, 5 historias de usuario, user story map, mockup interactivo y plantilla CORHUILA diligenciada
