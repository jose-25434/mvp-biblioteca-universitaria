# MVP – Sistema de Gestión de Biblioteca Universitaria

## Integrantes
- Jose Gabriel David Mendez Roncancio

## Descripción
MVP de un sistema web para automatizar préstamo, devolución, multas y notificaciones en la biblioteca universitaria. Diseño completo con UML, BPMN, requisitos funcionales/no funcionales, historias de usuario y prototipo.
