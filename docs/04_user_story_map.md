# User Story Map – MVP Biblioteca

## Épicas y Features

| Épica | Feature | Historias de usuario |
|-------|---------|----------------------|
| **Épica 1: Autenticación** | Inicio de sesión | HU: Login (no está en las 5 principales, pero se sobreentiende) |
| **Épica 2: Catálogo** | Búsqueda y visualización | HU #1: Buscar libro por título |
| **Épica 3: Préstamos** | Solicitar préstamo | HU #2: Realizar préstamo |
| **Épica 4: Devoluciones y multas** | Registrar devolución, calcular multa | HU #3: Devolución con multa |
| **Épica 5: Notificaciones** | Recordatorio vencimiento | HU #4: Correo de recordatorio |
| **Épica 6: Reportes** | Generar reporte CSV | HU #5: Reporte de préstamos activos |
